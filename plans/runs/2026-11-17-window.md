## The STOP File

At 21:33 alpha01 time (00:33 EST) an agent created $LASSI_RUNS_ROOT/rngd-sweep/STOP with tools/suite.py stop.
run-suite.sh's df figure rounds up, so with SUITE_MARGIN_GB=1 it starts a model at any free space above 60.0 GB, and
[PROJECTED] qwen3-32b would leave about 60.1 to 60.3 GB, so gemma4-31b would have started and taken the shared disk
about 1 GB below the gate's 60 GB floor while it ran. The STOP file was meant to keep that floor: the job made no
further call, wrote its tables, and ended with 60,743,016,448 bytes free (rx 20261117-221215-exec-cebb). The file stays
until the owner or an approved session clears it (tools/suite.py stop --clear); a new sweep job refuses to start while
it exists.
